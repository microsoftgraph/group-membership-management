# GMM Features

This document outlines some of GMM's current features.

| Feature Name | Description |
| --- | --- |
| Protection | Membership increase and decrease thresholds protect from erroneous changes in user attributes and facilitate large organizational transitions. Protects against potential issues with HR data accuracy and reliability. |
| Scale | Optimizes job distribution and minimizes run concurrency. Uses delta query and caching to reduce load on Graph. |
| Group Owner Submission | Allows group owners to onboard themselves. Includes a submission approval workflow for admins. |
| Multi-Source Support | Integrates with multiple data sources like Workday, SAP SuccessFactors, Oracle HCM, ADP Workforce Now, PowerSchool, Blackboard and other custom sources. |
| Multi-Destination Support | Supports Teams Channels membership in addition to Groups. |
